# 参考实现与改进

参考对象为「章鱼查币价」1.2.1 的本机安装包。以下结论来自实际代码阅读与隔离脚本复现；本项目重新实现，不包含原始源码。

| 参考实现的问题 | 本项目的处理 |
| --- | --- |
| 实际行情来源是 Gate.io，并非 Binance | 使用币安专用公开现货数据域名 |
| 请求失败后空价格仍视为成功、覆盖缓存 | 校验行情；失败保留上次报价和时间，并呈现离线状态 |
| 三分钟轮询，按币种分别请求 | WebSocket 推送 + 有上限的批量 REST 补数 |
| 小价格丢失有效位，大价格角标超长 | 完整价格保留十进制精度；角标按四字符预算缩写 |
| 非美元计价的币对显示美元符号 | 始终带实际 quoteAsset，如 ETH/BTC 的 BTC |
| 搜索选择被原列表过滤掉、详情恢复旧内容 | 目录与自选分离，保留精确选中币对并防请求竞态 |
| 弹窗打开后不能收到新行情 | 后台通过 port 广播，断开后自动重连 |
| 浏览器启动后没有可靠补建轮询 alarm | 每次 worker 初始化和启动事件检查 alarm |

附加优化包括持久化设置校验、最多 20 个自选、主题与颜色偏好、限流冷却、WebSocket 退避与轮换，以及构建和回归测试。首版独立实现为后续新增提醒等功能留出明确的模块边界。
