# USDT Perpetual Implementation Plan

> Use superpowers:subagent-driven-development for the independent market and popup tasks; controller integrates Chrome adapter and verifies the complete extension.

**Goal:** 搜索 BTWUSDT 永续并加入自选 / 角标，保留现货。
**Architecture:** 兼容旧数据的市场标识，双市场独立行情连接，统一自选展示。
**Tech Stack:** 保留 React / TypeScript / Vite / Vitest / Playwright。
**Spec:** docs/superpowers/specs/2026-09-18-usdm-design.md

## Global Constraints
- market 为 spot 或 usdm，旧数据无 market 视为 spot。
- key：现货原 symbol；合约 usdm:symbol；总自选上限 20。
- 永续最新成交价，USDT 结算，仅公开接口；REST 超时 8 秒，并发最多 4。
- 不引入新依赖、不启用受权限限制的 GitHub Actions。
