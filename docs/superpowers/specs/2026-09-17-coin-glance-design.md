# 蛋壳币价第一版设计（历史记录）

> 本文记录 0.1.0 的设计过程；当前功能和名称以根目录 README 为准。文件路径保留以兼容既有引用。

用户已授权在当前目录直接开发，使用推荐技术栈，初始化 Git 并新建 GitHub 仓库推送。

目标是无需打开网页即可从工具栏查看币安现货报价。新实现使用 Vite、TypeScript、React popup、Manifest V3 service worker，参考既有功能，自行实现代码和视觉设计。

## 范围与约束

- Chrome 120+，Node 22.12+；无需后台服务器、登录或 API Key。
- REST 使用 https://data-api.binance.vision，WebSocket 使用 wss://data-stream.binance.vision:443。
- 默认 BTC、ETH、SOL、BNB 等 USDT 交易对；支持从当前交易目录搜索、预览、添加不同报价单位的交易对；最多 20 个自选。
- 工具栏固定币种或每 5/10/15 秒轮播；显示价格或 24 小时涨跌幅；可选择红涨/绿涨。
- 弹窗 400px 宽，最大 600px 高，可滚动，支持明暗/系统主题、连接状态、精确报价单位、缓存状态、搜索和固定角标。
- 连接失败保留最后有效报价；更新时间只代表成功收到的行情；超过 60 秒的报价标记过期，不能伪称已连接。
- 价格字符串保留精度；角标尽量不超过 4 字符；极小值用明确数量级或非零提示，完整价在 tooltip。
- REST 请求 8 秒超时、批量请求、429/418 遵守 Retry-After；WebSocket 有退避、20 秒合法协议心跳、24 小时前轮换、旧连接事件隔离。
- 每次 worker 启动确保健康检查 alarm；断网、休眠后恢复；配置串行保存，行情快照限频保存。
- 搜索过滤本地目录；详情请求按选择身份隔离响应；弹窗实时订阅同一行情状态。
- 自动测试覆盖之前发现的数据、格式化、搜索和后台恢复问题；浏览器测试覆盖真实组件和打包扩展。
- GitHub 默认名称 vibe-coding-plugin、私有，若用户明确选择其他可见性则按其选择。推送前完成本地检查。

## 结构

`src/shared` 定义跨上下文协议、设置校验与格式化；`src/market` 负责币安网络和连接生命周期；`src/background` 适配 Chrome 存储、alarm、角标和消息；`src/popup` 负责交互。网络依赖与时钟边界可模拟，业务逻辑使用真实代码测试。

行情内存状态向 popup 广播，角标最多每秒重绘一次，本地缓存最多每 15 秒保存一次，设置立即持久化。开发预览明确标记示例数据，并由 Vite 开发条件隔离，生产扩展只显示真实行情或错误。

不在第一版中加入账户操作、交易、合约、到价提醒及第三方分析接口。提醒需要另行明确触发与冷却规则。
