# 角标优先显示价格数字

用户已确认此方案并授权在独立分支开发，本地验收后再决定合并。

- 目标：角标最多四字符，四位整数直接显示，五位整数舍弃个位；不使用 k 缩写占用这些价格的显示位置。
- 示例：`2428.76 → 2428`、`68754.32 → 6875`、`99999.90 → 9999`、`12.345 → 12.3`、`0.6073 → .607`。
- 普通价格截断而不进位；整数不补前导零，保留小数时不补无意义的末尾零。小于 1 的三位小数、极小价科学记数法沿用现有处理。
- 五位整数的悬停说明注明省略个位，同时保留完整价格和计价币种。
- 本轮不设计六位及以上价格的新规则，保留原有兜底；原生角标配色、字号、涨跌幅模式和行情获取方式沿用现状。
- 方案取舍：单位缩写会占用有效数字的位置；扩充角标字符数会改变原有显示预算，因此采用用户选择的高位数字截取。
