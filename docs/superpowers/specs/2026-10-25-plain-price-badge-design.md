# 角标优先显示价格数字

用户已确认此方案并授权在独立分支开发，本地验收后再决定合并。

- 目标：角标最多四字符，小数点也计入；四位整数直接显示，五位整数舍弃个位；不使用 k 缩写占用这些价格的显示位置。
- 示例：`2428.76 → 2428`、`68754.32 → 6875`、`99999.90 → 9999`、`1.7462 → 1.75`、`12.345 → 12.3`、`0.6073 → .607`。
- 四位与五位整数截断而不进位。较小价格按可显示的小数位四舍五入，并补小数末尾零（`1.2 → 1.20`、`12 → 12.0`）；整数不补前导零。进位后仍最多四字符（`9.9999 → 10.0`、`99.999 → 100`）。小于 1 保留三位小数，极小价保留科学记数法。
- 五位整数的悬停说明注明省略个位，同时保留完整价格和计价币种。
- 本轮不设计六位及以上价格的新规则，保留原有兜底；原生角标配色、字号、涨跌幅模式和行情获取方式沿用现状。
- 方案取舍：单位缩写会占用有效数字的位置；扩充角标字符数会改变原有显示预算，因此采用用户选择的高位数字截取。
- 交付：版本 0.2.5，从最新 main 创建功能分支，在同一项目中构建 dist 供本地验收。

验收反馈已确认：优先保证原生角标可读性，保持总共四字符，不采用“四个数字加小数点”的五字符方案。
