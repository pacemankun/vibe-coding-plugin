扩展处理的信息

蛋壳币价通过 chrome.storage.local 在用户自己的浏览器中保存自选交易对、角标和主题设置、币对目录，以及最近收到的公开行情。用户可以在扩展内修改或删除自选；卸载扩展会移除浏览器为它保存的本地数据。

扩展不要求注册或登录，不读取浏览记录、网页内容、联系人或币安账户，也不使用分析或广告追踪工具。

与币安的网络通信

为了展示价格，扩展直接连接币安的现货和 USDT 永续公开 REST / WebSocket 行情接口，并发送用户选择的交易对代码。请求时，币安作为第三方服务可能看到网络地址、请求时间和交易对代码；这些信息由币安按照其规则处理。

扩展不附带用户的币安账号凭据或 API Key，也不会把本地自选和行情上传到开发者控制的服务器。

自愿支持开发

扩展提供微信、支付宝及 USDT 收款码，仅供用户自愿打赏。扩展不在本机处理支付，不收集或保存付款人的姓名、账号、交易记录或付款金额。扫码或转账会进入相应的外部支付平台或区块链网络；这些第三方的处理规则由其各自决定。无论是否打赏，扩展功能都相同。

数据分享、安全与变更

除为获得公开行情而直接请求币安外，扩展不会向开发者或其他第三方出售或传送本地保存的设置与行情。网络行情连接使用 HTTPS / WSS；扩展不执行远程代码。

若以后新增数据处理方式，会在更新前修改本政策及商店隐私声明。问题或数据处理咨询请联系 398871200@qq.com。
