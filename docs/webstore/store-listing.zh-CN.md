## 详细描述

蛋壳币价（Danke Coin）让你在 Chrome 工具栏快速查看币安公开行情，无需反复打开交易页面。支持现货和 USDT 永续交易对，包括 BTW/USDT；点击图标即可查看完整价格、24 小时涨跌幅和自选列表。

你可以选择一个交易对固定到工具栏价格角标，也可以随时取消固定，让图标保持无数字。角标使用统一的浅青蓝背景和深色文字，以四字符近似值便于快速查看；完整价格以弹窗和图标悬停说明为准。支持自选轮换、浅色与深色主题，以及断线后的最近报价提示。

行情来自币安公开接口，不需要币安账号或 API Key。扩展在本机保存自选、显示设置和最近行情；请求行情时会向币安发送所选交易对。数据更新取决于浏览器后台运行状态、网络连接和币安服务。合约价格为最新成交价，并非标记价格。

扩展免费使用。弹窗内提供完全自愿的「投喂蛋壳」支持入口；不打赏也能使用全部行情功能。蛋壳币价是独立开发的第三方工具，并非币安官方产品，不提供交易、钱包连接或投资建议。

## 隐私字段填写依据

- 单一用途：在浏览器工具栏展示用户选择的币安现货与 USDT 永续公开价格行情。
- `storage`：在本机保存自选交易对、角标和主题设置、币对目录及最近行情，以便重启后恢复。
- `alarms`：定时检查并恢复后台行情连接；不读取浏览记录。
- `https://data-api.binance.vision/*`：获取币安现货币对目录及行情。
- `https://fapi.binance.com/*`：获取币安 USDT 永续币对目录及行情。
- 远程代码：否；远端只返回行情数据，执行代码均打包在扩展内。
- 用户数据声明：扩展不要求账号、不收集身份资料、浏览历史或支付信息，也不向开发者服务器发送数据；自选和设置保存在本机。所选交易对会随行情请求发送到币安，应在后台按字段实际定义如实填写，不要简单将所有选项勾为「否」。

## 审核测试说明

安装后点击工具栏图标，选择「添加币对」→「USDT 永续」→ 搜索 `BTW` → 加入自选。点击「固定到角标」可显示价格，再次点击可取消。设置页可切换价格/涨跌幅、轮换间隔和主题。行情需要网络可访问币安公开接口，无需登录或测试账号。
